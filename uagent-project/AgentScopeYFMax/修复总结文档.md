### 2.7 虚拟环境初始化顺序问题（新增）
**问题描述**: 
1. LLM 尝试执行 `.venv/bin/python` 或 `.venv\Scripts\python.exe` 时，虚拟环境尚未创建
2. `DependencyInstaller.installIfNeeded()` 在配置 ShellCommandTool **之后**才被调用
3. 如果虚拟环境创建失败，没有明确的错误提示
4. 已存在的 `.venv` 目录可能是损坏的虚拟环境，导致后续执行失败
5. **ShellCommandTool 未设置 workDir**，导致 LLM 在错误的目录下执行命令
6. Windows 控制台显示乱码（GBK 编码问题）

**解决方案**:
- **调整执行顺序**：在 `BaseSkillBoxFactory.java` 中，先调用 `DependencyInstaller.installIfNeeded()` 再配置 ShellCommandTool
- **设置 workDir**：通过 `codeExecution().workDir(localPath.toString())` 指定工作目录
- **增加验证逻辑**：在虚拟环境创建后验证其有效性（检查 Python 可执行文件是否存在）
- **清理损坏的虚拟环境**：在 `DependencyInstaller.java` 中检测并删除无效的 `.venv` 目录
- **增强错误日志**：在关键步骤添加详细的日志输出，便于排查问题
- **添加重试机制**：如果虚拟环境创建失败，提供更明确的错误信息

```java
// 检查并清理已存在的 .venv 目录（如果损坏）
Path venvPath = workDir.resolve(".venv");
if (Files.exists(venvPath)) {
    log.info("Found existing .venv directory at: {}", venvPath);
    // 验证是否为有效的虚拟环境
    boolean isValidVenv = isWindows()
            ? Files.exists(venvPath.resolve("Scripts").resolve("python.exe"))
            : Files.exists(venvPath.resolve("bin").resolve("python"));
    
    if (!isValidVenv) {
        log.warn("Existing .venv is not a valid virtual environment, will recreate...");
        try {
            // 删除无效的 .venv 目录
            deleteDirectory(venvPath);
            log.info("Deleted invalid .venv directory");
        } catch (IOException e) {
            log.error("Failed to delete invalid .venv directory", e);
            return false;
        }
    }
}

// 创建虚拟环境（如果已存在则清除）
log.info("Creating virtual environment with uv...");
if (!executeCommand(workDir, "uv", "venv", ".venv", "--python", "3.11", "--clear")) {
    log.warn("Failed to create venv with uv using Python 3.11, trying without --python flag...");
    if (!executeCommand(workDir, "uv", "venv", ".venv", "--clear")) {
        log.error("Failed to create virtual environment with uv. Please check if uv is installed and Python 3.11 is available.");
        return false;
    }
}

// 验证虚拟环境是否成功创建
if (!Files.exists(venvPath)) {
    log.error("Virtual environment was not created at: {}", venvPath);
    return false;
}

boolean isValidVenv = isWindows()
        ? Files.exists(venvPath.resolve("Scripts").resolve("python.exe"))
        : Files.exists(venvPath.resolve("bin").resolve("python"));

if (!isValidVenv) {
    log.error("Virtual environment created but Python executable not found. This may indicate a corrupted venv.");
    return false;
}

log.info("✅ Virtual environment created successfully at: {}", venvPath);
```

**新增辅助方法 - 递归删除目录**:
```java
/**
 * 递归删除目录及其所有内容
 *
 * @param directory 要删除的目录
 * @throws IOException 如果删除失败
 */
private static void deleteDirectory(Path directory) throws IOException {
    if (!Files.exists(directory)) {
        return;
    }

    try (java.util.stream.Stream<Path> walk = Files.walk(directory)) {
        walk.sorted(java.util.Comparator.reverseOrder())
                .forEach(path -> {
                    try {
                        Files.delete(path);
                    } catch (IOException e) {
                        log.warn("Failed to delete: {}", path, e);
                    }
                });
    }
}
```

### 3.4 ShellCommandTool 配置 (`BaseSkillBoxFactory.java`)

**操作系统自动检测**:
```java
private static String getVenvPythonPath(Path workDir) {
    String os = System.getProperty("os.name", "").toLowerCase();
    if (os.contains("win")) {
        return ".venv\\Scripts\\python.exe";
    } else {
        return ".venv/bin/python";
    }
}
```

**调整执行顺序（新增）**:
```java
if (localPath != null) {
    // ⚠️ 重要：先安装 Python 依赖（如果存在 requirements.txt）
    // 必须在配置 ShellCommandTool 之前，确保 .venv 目录已创建
    boolean depsInstalled = DependencyInstaller.installIfNeeded(localPath);
    if (!depsInstalled) {
        log.error("❌ Failed to install dependencies for repo: {}. Code execution may not work properly.", repoUrl);
    }

    // 自动检测操作系统并获取虚拟环境 Python 路径
    String venvPython = getVenvPythonPath(localPath);
    log.info("🔍 Detected OS: {}, venv Python: {}", System.getProperty("os.name"), venvPython);

    // 验证虚拟环境是否存在
    Path venvPath = localPath.resolve(".venv");
    if (!java.nio.file.Files.exists(venvPath)) {
        log.error("❌ Virtual environment not found at: {}. This may cause Python script execution failures.", venvPath);
    } else {
        log.info("✅ Virtual environment exists at: {}", venvPath);
    }

    ShellCommandTool customShell = new ShellCommandTool(
        null,  // baseDir 会被自动覆盖为 workDir
        Set.of("uv", "node", "npm", "python", "python3", venvPython),
        command -> {
            log.info("Approval callback for command: {}", command);
            return true;  // 自动批准所有命令
        }
    );
    // ⚠️ 重要：设置 workDir 为仓库根目录（LLM 执行 Shell 命令的默认目录）
    this.skillBox.codeExecution()
        .workDir(localPath.toString())  // ✅ 指定工作目录
        .withShell(customShell)
        .withRead()
        .withWrite()
        .enable();

    // 配置 Python 路径：检测 skills/ 下的模块目录，创建 .pth 文件
    PythonPathSetup.setupIfNeeded(localPath);
}
```

**关键修改说明**：
- **之前**：`codeExecution().withShell(customShell)...` （没有设置 workDir）
- **之后**：`codeExecution().workDir(localPath.toString()).withShell(customShell)...` （明确指定工作目录）
- **影响**：LLM 执行 `.venv\Scripts\python.exe` 时，会在正确的目录下查找该文件

**ShellCommandTool 配置**:
```java
String venvPython = getVenvPythonPath(localPath);
ShellCommandTool customShell = new ShellCommandTool(
    null,  // baseDir 会被自动覆盖为 workDir
    Set.of("uv", "node", "npm", "python", "python3", venvPython),
    command -> {
        log.info("Approval callback for command: {}", command);
        return true;  // 自动批准所有命令
    }
);
this.skillBox.codeExecution()
    .withShell(customShell)
    .withRead()
    .withWrite()
    .enable();
```

## 5. 注意事项

### 5.1 LLM 行为控制
- LLM 的行为主要通过 SKILL.md 提示词控制
- 需要在所有相关 SKILL.md 文件中添加明确的禁令
- 定期检查 LLM 是否遵循正确的命令格式

### 5.2 操作系统兼容性
- 代码自动检测操作系统类型，无需手动配置
- 在 Windows 上使用 `.venv\Scripts\python.exe`
- 在 Linux/macOS 上使用 `.venv/bin/python`

### 5.3 安全策略
- ShellCommandTool 白名单应保持最小化原则
- 审批回调函数当前设置为自动批准所有命令
- 生产环境中应考虑更严格的命令审批机制

### 5.4 会话管理
- 使用 `threadID` 作为会话标识符
- 会话级缓存在会话结束后应清理
- 确保会话隔离不会影响其他会话的正常运行
