**更新日期**: 2026-06-12  
**核心思想**: 只保留数据库和企业微信配置，移除 AI、Flask、JWT 等无关配置

## 📝 配置内容

### application.yml 配置

在 `start/src/main/resources/application.yml` 中添加：

```yaml
skill:
  config:
    # ---------------------------------------------------------------------------
    # 数据查询统计数据库配置
    # ---------------------------------------------------------------------------
    database:
      host: ${DB_HOST:8.129.128.167}
      port: ${DB_PORT:3306}
      name: ${DB_NAME:menu_recommand}
      user: ${DB_USER:root}
      password: ${DB_PASSWORD:}
    
    # ---------------------------------------------------------------------------
    # DataPlatform 数据库配置（etl_order_data_daily 所在库）
    # ---------------------------------------------------------------------------
    dataplatform:
      host: ${DP_HOST:8.129.128.167}
      port: ${DP_PORT:3306}
      name: ${DP_NAME:dp}
      user: ${DP_USER:root}
      password: ${DP_PASSWORD:}
    
    # ---------------------------------------------------------------------------
    # 对话存储数据库配置
    # ---------------------------------------------------------------------------
    conversation-db:
      host: ${CONVERSATION_DB_HOST:8.129.128.167}
      port: ${CONVERSATION_DB_PORT:3306}
      name: ${CONVERSATION_DB_NAME:conversation_db}
      user: ${CONVERSATION_DB_USER:root}
      password: ${CONVERSATION_DB_PASSWORD:}
    
    # ---------------------------------------------------------------------------
    # 企业微信机器人开关
    # ---------------------------------------------------------------------------
    wecom:
      enabled: ${WECOM_ENABLED:true}
```

## 🎯 架构说明

### 配置流转路径

```
application.yml (Spring Boot)
    ↓
@ConfigurationProperties (SkillConfigProperties)
    ↓
@Autowired 注入到 SkillEnvConfigManager
    ↓
生成 skills/config/.env 和 skills/config/config.yaml
    ↓
Python Skill 加载配置
```

### 代码结构

```
AgentScopeYFMax/
├── src/main/java/org/example/agentScope/util/skill/
│   ├── SkillConfigProperties.java          ← @ConfigurationProperties 绑定 YAML
│   └── SkillEnvConfigManager.java          ← 读取配置并生成 .env / config.yaml
└── ...

start/
└── src/main/resources/
    └── application.yml                      ← 实际配置存放位置
```

## 💡 使用方式

### 方式 1：直接在 application.yml 中配置

```yaml
skill:
  config:
    database:
      host: 8.129.128.167
      user: your_user
      password: your_password
```

### 方式 2：通过环境变量覆盖

创建 `.env` 文件（不提交到 Git）：

```bash
DB_HOST=8.129.128.167
DB_USER=your_user
DB_PASSWORD=your_password
DP_HOST=8.129.128.167
DP_USER=your_dp_user
DP_PASSWORD=your_dp_password
CONVERSATION_DB_HOST=8.129.128.167
CONVERSATION_DB_USER=your_conv_user
CONVERSATION_DB_PASSWORD=your_conv_password
WECOM_ENABLED=true
```

启动前加载：

```powershell
# Windows PowerShell
Get-Content .env | ForEach-Object { 
  if ($_ -match '^([^#][^=]+)=(.*)$') { 
    [Environment]::SetEnvironmentVariable($matches[1], $matches[2], 'Process') 
  } 
}
java --enable-preview -jar uagent.jar
```
