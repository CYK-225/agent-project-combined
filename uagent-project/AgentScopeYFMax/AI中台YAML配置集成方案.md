# AI 中台 YAML 配置集成方案

**实现日期**: 2026-06-12  
**核心思想**: 配置存储在 AI 中台的 YAML 文件中，Java 通过 `@ConfigurationProperties` 读取，生成 `.env` 文件

---

## 🎯 方案架构

### 配置流转路径

```
AI 中台 YAML 配置
    ↓
application.yml (Spring Boot)
    ↓
@ConfigurationProperties (SkillConfigProperties)
    ↓
@Value / @Autowired 注入
    ↓
SkillEnvConfigManager 读取配置
    ↓
生成 config/.env 和 config/config.yaml
    ↓
Python Skill 加载配置
```

---

## 📝 配置方式

### 方式 1：在 application.yml 中配置（推荐）

在 Spring Boot 应用的 `application.yml` 中添加：

```yaml
skill:
  config:
    # 数据查询统计数据库配置
    database:
      host: 8.129.128.167
      port: 3306
      name: menu_recommand
      user: your_user
      password: your_password
    
    # DataPlatform 数据库配置
    dataplatform:
      host: 8.129.128.167
      port: 3306
      name: dp
      user: your_user
      password: your_password
    
    # 对话存储数据库配置
    conversation-db:
      host: 8.129.128.167
      port: 3306
      name: conversation_db
      user: your_user
      password: your_password
    
    # AI API 配置
    ai:
      api-url: https://api.deepseek.com/v1
      api-key: sk-your-api-key
      model: deepseek-chat
    
    # Flask 配置
    flask:
      host: 0.0.0.0
      port: 5000
      debug: false
    
    # 前端 URL
    frontend-url: http://localhost:5173
    
    # JWT 配置
    jwt:
      secret-key: your-jwt-secret-key
      algorithm: HS256
    
    # 企业微信配置
    wecom:
      enabled: true
```

### 方式 2：使用 @Value 注解

在需要直接使用配置的地方：

```java
@Component
public class SomeService {
    
    @Value("${skill.config.database.host}")
    private String dbHost;
    
    @Value("${skill.config.database.port}")
    private Integer dbPort;
    
    // ...
}
```

## 🔧 技术实现

### 1. SkillConfigProperties（配置属性类）

**位置**: `org.example.agentScope.util.skill.SkillConfigProperties`

**功能**:
- 使用 `@ConfigurationProperties(prefix = "skill.config")` 自动绑定 YAML 配置
- 提供 `toFlatMap()` 方法转换为扁平结构（用于生成 .env）
- 提供 `toNestedMap()` 方法保持分层结构（用于生成 config.yaml）

**关键代码**:
```java
@Data
@Component
@ConfigurationProperties(prefix = "skill.config")
public class SkillConfigProperties {
    private DatabaseConfig database;
    private DatabaseConfig dataplatform;
    private DatabaseConfig conversationDb;
    private AiConfig ai;
    private FlaskConfig flask;
    private String frontendUrl;
    private JwtConfig jwt;
    private WecomConfig wecom;
    
    // 转换为扁平 Map（用于 .env）
    public Map<String, String> toFlatMap() { ... }
    
    // 转换为分层 Map（用于 YAML）
    public Map<String, Object> toNestedMap() { ... }
}
```

### 2. SkillEnvConfigManager（配置管理器）

**修改内容**:
- 注入 `SkillConfigProperties`
- 优先从 Spring 配置读取
- 降级到默认配置模板

**配置优先级**:
```
1. SkillConfigProperties (Spring YAML / @Value) ← 最高优先级
2. AI 中台 API (TODO)
3. 默认配置模板 ← 最低优先级
```

**关键代码**:
```java
@Autowired(required = false)
private SkillConfigProperties skillConfig;

private Map<String, String> getConfig(String repoUrl, String envName) {
    // 优先从 Spring 配置读取
    if (skillConfig != null) {
        log.info("✅ Using Spring configuration (application.yml / @Value)");
        return skillConfig.toFlatMap();
    }
    
    // 否则使用默认配置
    log.warn("⚠️ Using default config template");
    return DEFAULT_CONFIG_TEMPLATE;
}
```

## 🔄 多环境支持

### 使用 Spring Profile

创建不同环境的配置文件：

**application-dev.yml**:
```yaml
skill:
  config:
    database:
      host: localhost
      port: 3306
      user: dev_user
      password: dev_pass
```

**application-prod.yml**:
```yaml
skill:
  config:
    database:
      host: prod-db.example.com
      port: 3306
      user: prod_user
      password: ${DB_PASSWORD}  # 从环境变量读取
```

### 启动时指定环境

```bash
# 开发环境
java -Dspring.profiles.active=dev --enable-preview -jar uagent.jar

# 生产环境
java -Dspring.profiles.active=prod --enable-preview -jar uagent.jar
```

## 🛡️ 安全性最佳实践

### 1. 敏感信息不硬编码

❌ **错误做法**:
```yaml
skill:
  config:
    database:
      password: "actual_password_here"  # ❌ 不要硬编码
```

✅ **正确做法**:
```yaml
skill:
  config:
    database:
      password: ${DB_PASSWORD}  # ✅ 从环境变量读取
```

启动时设置环境变量：
```bash
export DB_PASSWORD="actual_password"
java --enable-preview -jar uagent.jar
```

### 2. 使用密钥管理系统

集成 HashiCorp Vault、AWS Secrets Manager 等：

```yaml
skill:
  config:
    database:
      password: ${vault:secret/data/db/prod#password}
```

### 3. .gitignore 配置

确保配置文件不被提交：

```gitignore
# application-local.yml（本地配置）
application-local.yml

# 生成的 .env 文件
**/config/.env
**/config/config.yaml
```

## 📊 优势总结

### vs 手动配置 .env

| 对比项 | 手动配置 | Spring YAML + 自动生成 |
|--------|----------|----------------------|
| 配置管理 | ❌ 分散在各处 | ✅ 集中在 application.yml |
| 类型安全 | ❌ 全是字符串 | ✅ 强类型（int/bool/string） |
| IDE 支持 | ❌ 无提示 | ✅ 自动补全、验证 |
| 多环境 | ❌ 需维护多个文件 | ✅ Spring Profile |
| 密钥管理 | ❌ 容易泄露 | ✅ 支持环境变量/Vault |
| 自动化 | ❌ 手动创建 | ✅ 自动生成 |

### vs 硬编码配置

| 对比项 | 硬编码 | Spring YAML |
|--------|--------|-------------|
| 灵活性 | ❌ 需重新编译 | ✅ 外部化配置 |
| 安全性 | ❌ 密钥在代码中 | ✅ 可加密/外部化 |
| 可维护性 | ❌ 分散在代码中 | ✅ 集中管理 |
| 多租户 | ❌ 不支持 | ✅ 每个租户独立配置 |

```json

    "prod": {

        "port": 3306,
        "user": "prod_user",
        "password_encrypted": "enc(...)"

```

### Java 应用获取配置

```java
// TODO: 实现从 AI 中台 API 获取配置
private Map<String, String> fetchFromAIPlatform(String repoUrl, String envName) {
    String apiUrl = "https://ai-platform.example.com/api/skill/config";
    String url = apiUrl + "?repo=" + URLEncoder.encode(repoUrl) + "&env=" + envName;
    
    HttpClient client = HttpClient.newHttpClient();
    HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create(url))
        .header("Authorization", "Bearer " + getAuthToken())
        .GET()
        .build();
    
    HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
    
    if (response.statusCode() == 200) {
        // 解析 YAML 响应
        Yaml yaml = new Yaml();
        Map<String, Object> yamlData = yaml.load(response.body());
        
        // 转换为扁平配置
        return convertToFlatMap(yamlData);
    }
    
    return null;
}
```
